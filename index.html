📊 Statistiky hráčů

Statistiky standardně počítají pouze proběhlé události. Nominace se bere jako účast, ale ručně upravená docházka má přednost. Poměr ukazuje účasti z celkového počtu proběhlých akcí.

Opravit účast na zápase

Zaškrtnutí označuje hráče, kteří skutečně nastoupili. Pokud účast ještě nebyla ručně opravena, statistika vychází automaticky z nominace.

🛡️ Zálohování a obnova

Záloha obsahuje soupisku, události, nominace, sestavy a ručně upravenou účast. Ulož si ji pravidelně do aplikace Soubory na iPhonu.

Záloha na GitHub

Aplikace běží přímo v prohlížeči, proto bezpečně neukládá GitHub přístupový token do HTML. Po stažení JSON můžeš soubor nahrát do svého repozitáře jako backup/fotbalova-nominace.json. Při obnově ho zase stáhneš a vybereš výše.

Doporučení: po každé větší změně nominací stáhni zálohu a ulož ji do iCloudu nebo na GitHub. Aktualizace aplikace nemá mazat data uložená v tomto telefonu.

🖼️ Import a export rozpisu

Můžeš načíst rozpis z fotky pomocí rozpoznávání textu, nebo pohodlněji importovat tabulku připravenou v Excelu. Pro Excel ulož soubor jako CSV UTF-8 a nahraj ho níže. Sloupce mohou obsahovat datum, název akce, sraz, výkop, povrch, místo, adresu a poznámku.

Import přidává události ke stávajícím. Před uložením se vyhledají duplicity podle data a názvu.
