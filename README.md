# Fotbalová nominace ⚽

Kalendář akcí, soupiska hráčů a generátor nominací pro WhatsApp.

## Nasazení
Nahrajte `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png` a `icon-512.png` do kořene větve `main` v novém repozitáři. V Settings → Pages zvolte Deploy from a branch, `main`, `/(root)` a uložte. Pak otevřete publikovanou adresu v Safari na iPhonu a zvolte Sdílet → Přidat na plochu.

## Poznámky
Data jsou uložena lokálně v tomto prohlížeči. Aplikace nepíše přímo do WhatsApp skupiny; vytvoří text, který zkopírujete nebo nasdílíte. Obsahuje ukázkovou akci Turnaj Nymburk, kterou lze upravit nebo smazat.
